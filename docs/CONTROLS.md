# 🎮 DangoPlayer Switch — Mapeo de Controles

Guía de control para Nintendo Switch en modo portátil (Handheld), controles acoplados/desacoplados (Joy-Cons) y Nintendo Switch Pro Controller.

---

## 📱 Controles Táctiles (Pantalla Táctil Capacitiva)

La pantalla multitáctil de la Nintendo Switch está soportada de forma nativa en todos los menús y en el reproductor.

| Acción | Gesto Táctil |
|---|---|
| **Seleccionar elemento** | Toque simple (*Tap*) en cualquier tarjeta o botón |
| **Hacer scroll en listas** | Arrastrar el dedo verticalmente hacia arriba o abajo (*Swipe / Drag*) |
| **Play / Pause** | Toque en el centro de la pantalla mientras se reproduce |
| **Desplazamiento temporal (Seek)** | Deslizar el dedo sobre la barra de progreso inferior |
| **Cambiar grupo / categoría** | Toque sobre la píldora de categoría en la barra superior |
| **Regresar / Subir carpeta** | Toque en el botón `[B] Atrás` de la esquina superior izquierda |

---

## 🕹️ Navegación General (Menús y Explorador)

| Botón | Joy-Con / Pro Controller | Función |
|---|---|---|
| **D-Pad / Stick Izquierdo** | ↑ / ↓ / ← / → | Desplazar el cursor entre tarjetas o elementos |
| **A** | Botón A | Seleccionar, abrir carpeta o iniciar reproducción |
| **B** | Botón B | Regresar a la pantalla anterior o subir un nivel de carpeta (`..`) |
| **X** | Botón X | Alternar filtros en explorador o eliminar listas guardadas |
| **Y** | Botón Y | Alternar unidad de almacenamiento (`sdmc:/` Tarjeta SD ⟷ `ums0:/` USB) |
| **L / R** | Gatillos superiores | Retroceder o avanzar de página en listas largas (Page Up / Page Down) |
| **+ (Plus)** | Botón + | Salir de la aplicación hacia el Homebrew Menu |

## 🎬 Controles en el Reproductor de Video

Durante la reproducción de videos locales o streams IPTV en vivo:

| Botón | Función |
|---|---|
| **A** | Alternar entre **Pausa** y **Reproducción** |
| **D-Pad ←** | Retroceso rápido relativo de **-10 segundos** |
| **D-Pad →** | Avance rápido relativo de **+10 segundos** |
| **ZL** | Salto grande de **-60 segundos** (-1 minuto) |
| **ZR** | Salto grande de **+60 segundos** (+1 minuto) |
| **D-Pad ↑** | Subir volumen (+5%) |
| **D-Pad ↓** | Bajar volumen (-5%) |
| **X** | Abrir menú modal de **Pistas de Audio** |
| **Y** | Abrir menú modal de **Subtítulos** (`.srt` / `.ass`) |
| **B** | Detener reproducción y volver al explorador de archivos o lista |
| **Toque en pantalla** | Mostrar u ocultar el HUD con barra de progreso |

---

## 📺 Controles en el Navegador IPTV

| Botón | Función |
|---|---|
| **A** | Reproducir el canal de televisión en vivo seleccionado |
| **L / R** | Cambiar entre categorías y grupos de canales (`group-title`) |
| **ZL** | Marcar o desmarcar el canal como **Favorito ⭐** |
| **Y** | Abrir el teclado virtual para **Buscar canales por nombre** |
| **B** | Regresar a la lista de playlists guardadas |
